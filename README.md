# Papo de Homem para Homem — Node.js + Supabase

Site servido por Node.js/Express, integrado ao Supabase por uma API no servidor.
O quiz é carregado das tabelas `quizzes` e `perguntas`; vídeos podem ser
consultados em `/api/videos`.

As instruções completas estão em `GUIA-DE-INSTALACAO.md`.

```bash
npm install
npm start
```

Acesse `http://localhost:3000`.
